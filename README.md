# Recommendation A/B Testing with Imperfect Compliance

This project implements causal inference methods for experimentation with imperfect compliance using the EconML library.

## Overview
In many real-world A/B tests, users cannot be forced to comply with treatment. This notebook demonstrates how instrumental variable (IV) methods can recover causal effects in such settings.

## Methods Used
- Intent-to-Treat framework
- Instrumental Variables
- Doubly Robust IV (IntentToTreatDRIV)
- Heterogeneous Treatment Effects
- Policy and CATE interpreters

## Tools
- Python
- EconML
- Scikit-learn
- LightGBM
- Jupyter Notebook
